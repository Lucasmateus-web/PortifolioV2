

# Portfolio Profissional — LM | Software Engineer

## Visão Geral
Portfólio premium de alto padrão internacional para Software Engineer com foco em Front-End e UI/UX. Design tecnológico, minimalista e estratégico, com sensação de produto SaaS premium.

---

## 1. Design System & Tema
- Paleta de cores tecnológica (azul neon, roxo, ciano) para dark e light mode
- Toggle animado de dark/light mode com transição suave
- Tipografia: Inter (primária) + Space Grotesk (títulos)
- Layout baseado em grid 8px com muito espaço negativo
- Glass effects, sombras tecnológicas suaves, bordas 12-16px

## 2. Logo LM
- Monograma geométrico minimalista SVG com as iniciais "LM"
- Linhas vetoriais finas, corte angular, estilo flat + futurista
- Versão com glow azul/ciano no dark mode e versão sólida no light mode

## 3. Hero Section
- Gradiente animado sutil azul → roxo como fundo
- Nome com efeito typewriter animado
- Headline: "Software Engineer | Front-End Specialist | UI/UX Focused Developer"
- Subheadline estratégica
- Botões CTA: "View Projects" e "Contact Me"

## 4. Navegação & Multi-idioma
- Header fixo com logo, links de navegação e seletor de idioma (EN/PT/ES)
- Rotas: `/en`, `/pt`, `/es`
- Sistema de tradução para todo o conteúdo do site
- Navbar colapsável responsiva para mobile

## 5. Seção About
- Apresentação profissional com foco em maturidade técnica e experiência corporativa
- Destaque para arquitetura escalável, UI/UX e mentalidade orientada a produto

## 6. Seção Projects (5 projetos reais)

## 7. Seção Skills

## 8. Seção Experience
